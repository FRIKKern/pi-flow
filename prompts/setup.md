# pi-cursor setup

Kjør i Pi:

```
/pi-cursor-setup
```

Deretter:

1. `/login cursor` — Cursor-abonnement (Composer 2.5)
2. `/model` → **composer-2.5** (eller composer-2.5-fast)
3. Kopier `.mcp.json.example` → `.mcp.json` i prosjektrot
4. `/mcp setup` — importer eller legg til MCP-servere
5. `/pi-cursor-doctor` — sanity check

Start arbeid:

```text
Bruk scout til å forstå [område], deretter worker for [oppgave].
```
